# 언리얼 프로젝트

게임의 전체적인 이동 흐름은 다음과 같습니다. 개별 노드의 이벤트가 종료되면 유기적으로 월드맵으로 복귀하여 다음 경로를 선택합니다.

`Map_Title` ➡️ `Map_World` ➡️ `[개별 이벤트 맵]` ➡️ `Map_World` 복귀

### 📍 상세 레벨(Level) 설명

* **`Map_Title` (타이틀 맵)**
  * 게임 진입을 위한 초기 화면입니다. (게임 시작 버튼 구현)
    
* **`Map_World` (메인 월드맵)**
  * 로그라이크의 메인 진척도를 보여주는 화면입니다.
  * 현재 위치에서 근접한 노드로만 이동이 가능하도록 로직이 구현되어 있습니다.
  * 선택한 노드의 타입(`None`, `Combat`, `Shop`, `Boss`)에 따라 스위치(Switch)되어 각기 다른 맵으로 이동합니다.
    
* **`Map2` (전투 / 보스 맵)**
  * 적과 턴제 전투를 벌이는 메인 맵입니다.
    
* **`Map_ShopTest` (상점 맵 - 🚧 수정 중)**
  * 골드를 소모해 덱을 구매하는 임시 상점 맵입니다.
  * (현재 프로젝트 내 실행 시 충돌/버그가 발생하여 원인 파악 및 로직 수정 작업 중에 있습니다.)
